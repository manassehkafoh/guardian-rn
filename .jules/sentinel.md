## 2023-09-03 - Insecure Randomness in Session ID Generation
**Vulnerability:** The `generateSessionId` function used `Math.random()` to generate UUIDs. `Math.random()` is not a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG), making the generated UUIDs predictable. This predictability could allow an attacker to guess session IDs and potentially hijack sessions or bypass security controls reliant on session uniqueness.
**Learning:** In React Native environments, the global `crypto` object is not available by default. Relying on custom `Math.random()`-based UUID generators is an insecure practice.
**Prevention:** Always use established, secure libraries for generating UUIDs, such as the `uuid` package (`uuidv4`). In React Native, this necessitates installing and correctly importing the `react-native-get-random-values` polyfill *before* the `uuid` library to ensure it utilizes a true CSPRNG (like the device's secure enclave) rather than falling back to an insecure entropy source.
