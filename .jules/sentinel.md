## 2024-07-21 - Hardcoded Credentials in Docker Compose
**Vulnerability:** Found hardcoded passwords (`ELASTIC_PASSWORD=changeme`, `ELASTICSEARCH_PASSWORD=changeme`, `GF_SECURITY_ADMIN_PASSWORD=admin`) in `packages/collector/docker-compose.yml`. This is a critical security risk as it exposes administrative credentials in plaintext, and users deploying the application directly might use these default weak passwords in production.
**Learning:** Default passwords are a common source of compromise in containerized setups. When defining inline shell commands in `docker-compose.yml` (e.g., within `healthcheck` blocks) that require interpolating environment variables, we must use a double dollar sign (e.g., `$${ELASTIC_PASSWORD}`) to prevent `docker-compose` from interpreting it early on the host. This ensures the literal string is passed to and evaluated correctly by the container's shell.
**Prevention:** Never use hardcoded default passwords or fallback defaults in Docker Compose configurations. Require explicit environment variables and provide a `.env.example` file to guide secure deployment.
