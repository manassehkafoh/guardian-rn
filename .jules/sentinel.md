## 2024-08-05 - Hardcoded Passwords in Docker Compose Configuration
**Vulnerability:** The `packages/collector/docker-compose.yml` file contained hardcoded passwords for Elasticsearch (`changeme`) and Grafana (`admin`), which could easily be pushed to a repository or used maliciously in out-of-the-box deployments.
**Learning:** Hardcoded credentials within orchestration files often stem from a desire to ease the out-of-the-box developer experience. However, doing so leaks critical deployment secrets. The `healthcheck` directive requires specific syntax (`$${VAR}`) when referencing environment variables to avoid the variable being evaluated locally before being passed to the container context.
**Prevention:** Always extract secrets to environment variables, ensure the `healthcheck` properly escapes variables, and supply a `.env.example` file that declares all uniquely named variables (e.g., `ELASTICSEARCH_PASSWORD`) so developers are forced to define them securely and the application doesn't fail on initial boot.
