## 2024-10-19 - [Harden Session Key Generation Fallback]
**Vulnerability:** The session key generation in `generateSessionKey()` used `Math.random()` as a fallback when the native `GuardianKeyProvider` module was unavailable. While documented as a test/CI fallback, it did not explicitly prevent usage in production environments lacking the native module or global crypto. `Math.random()` is not a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG), potentially leading to predictable HMAC session keys.
**Learning:** Native module failures (e.g., failed bridging or unsupported platforms) would silently degrade to an insecure cryptographic fallback without alerting the developer or application.
**Prevention:** Always enforce a strict environment check (e.g., `__DEV__` or `NODE_ENV === 'production'`) before falling back to insecure algorithms like `Math.random()`. Prefer standard web `crypto.getRandomValues()` when available, and strictly throw an error in production if no secure entropy source is present, rather than silently degrading security.
