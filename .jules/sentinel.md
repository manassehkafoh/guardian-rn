## 2026-07-29 - Hardcoded Infrastructure Credentials & Shell Interpolation
**Vulnerability:** Hardcoded credentials (`changeme`, `admin`) in `packages/collector/docker-compose.yml` for Elasticsearch, Logstash, Kibana, and Grafana.
**Learning:** Hardcoded credentials in infrastructure configuration files pose a critical security risk. When extracting credentials to environment variables that are interpolated in Docker Compose `healthcheck` shell commands, single dollar signs (e.g., `$ELASTIC_PASSWORD`) are resolved on the host during `docker compose up`, not within the container.
**Prevention:** Always use `.env` files or environment variables for sensitive infrastructure configuration. When referring to these variables within inline shell commands in `docker-compose.yml` (like in `healthcheck`), use a double dollar sign (e.g., `$$ELASTIC_PASSWORD`) to delay evaluation so the container shell interpolates it correctly at runtime. Supply a `.env.example` file to declare all required variables.
