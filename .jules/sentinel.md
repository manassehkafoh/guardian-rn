## 2026-07-27 - Hardcoded Passwords in Docker Compose Configurations
**Vulnerability:** The `packages/collector/docker-compose.yml` file contained hardcoded passwords for `ELASTIC_PASSWORD`, `ELASTICSEARCH_PASSWORD`, and `GF_SECURITY_ADMIN_PASSWORD` (`changeme`, `admin`), introducing critical security risks by exposing sensitive credentials in version control.
**Learning:** Even internal or local-focused tooling environments can become exploitable if deployed to public or shared systems with default, easily guessable credentials. Docker compose configurations often get copy-pasted directly to production. Furthermore, interpolating environment variables in healthcheck blocks requires `$$` escaping to evaluate correctly within the container's shell rather than the host context.
**Prevention:** Always externalize sensitive credentials in Docker Compose files using environment variables (`${VAR_NAME}`) and provide an accompanying `.env.example` file that outlines the expected configuration structure without providing sensitive defaults.
